# Latin incipits for the psalter and the canticles.
#
# Printed diurnals label each psalm with its Latin incipit as well as its
# number ("Psalm 67 · Deus misereatur"), and the parish prints them on its
# Lauds and Vespers handouts. This file supplies that subtitle; the office
# engine attaches it to the composed psalm or canticle element and every
# renderer shows it beside the label.
#
# Format:  <corpus-key> = <incipit>
#
# The key is a psalms/ or canticles/ corpus key. Every such entry must have a
# line here; `office validate` fails if one is missing or names a key that is
# not in the corpus.
#
# This file records a property of a text rather than being one, so — like
# data/collect-conclusions.txt — it lives outside data/texts/. That keeps the
# incipits out of the rendered-entry, provenance and zero-occurrence sweeps,
# and keeps 189 Latin labels from being flagged by the corpus Latin lint.
#
# NUMBERING
#
# The psalter is Coverdale (Book of Common Prayer), which uses HEBREW psalm
# numbering. The Latin tradition — and Divinum Officium — uses VULGATE
# (Septuagint) numbering, which runs one behind through most of the psalter
# and divides several psalms differently. The incipit on each line below is
# the incipit of the SAME psalm as the key, expressed in Latin; it is NOT the
# incipit of the Vulgate psalm that happens to share the number. So
# "psalms/067 = Deus misereatur nostri" pairs our Psalm 67 (Coverdale "God be
# merciful unto us") with Vulgate 66, which is the same psalm. The joins and
# splits were mapped individually:
#
#   Coverdale 1-8     = Vulgate 1-8
#   Coverdale 9       = Vulgate 9:2-21     (Vulgate 9 carries a title verse)
#   Coverdale 10      = Vulgate 9:22-39
#   Coverdale 11-113  = Vulgate 10-112
#   Coverdale 114     = Vulgate 113:1-8
#   Coverdale 115     = Vulgate 113:9-26
#   Coverdale 116     = Vulgate 114 + 115
#   Coverdale 117-146 = Vulgate 116-145
#   Coverdale 147     = Vulgate 146 + 147
#   Coverdale 148-150 = Vulgate 148-150
#
# Within a psalm, Coverdale verse n is Vulgate verse n plus the psalm's title
# verses (one for most psalms, two for Coverdale 51 = Vulgate 50). Our split
# psalms (009a/009b, 018a/018b, 119-i…119-xxii, 148a/148b, and the rest) take
# the incipit of the Latin verse that opens THAT part, not of the whole psalm.
#
# SOURCE: divinum-officium web/www/horas/Latin/Psalterium/Psalmorum — check
# against diurnal. Each incipit is the opening words of the Latin verse that
# begins the entry, mapped as above; the number of words kept is an editorial
# choice, trimmed to the conventional length and lengthened where two psalms
# would otherwise carry the same subtitle (Ad te, In te, Miserere mei, Dominus
# regnavit). Incipits that are genuinely identical in Latin are left identical
# (Psalms 6 and 38, 14 and 53, 96/98/149, 103 and 104, 107/118/136).
# Accents are dropped, since these are labels rather than pointed chant text;
# the Æ/æ and diaeresis spellings of the source are kept.
#
# Canticle incipits come from the same Divinum Officium psalter directory
# (Psalm210 Benedicite, Psalm216 Sirach, Psalm221-226 the ferial Old-Testament
# canticles, Psalm231-233 Benedictus/Magnificat/Nunc dimittis).
