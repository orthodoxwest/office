# false positive in the audit report.

#   feast-id *                 suppress all missing-proper warnings for this feast
#   feast-id ref1 ref2 ...     suppress only the named refs (see list below)
#
# Valid refs:
#   psalm-antiphon         benedictus-antiphon    magnificat-antiphon

#
# Example:
#   st-raphael-of-brooklyn *
#   some-martyr commemoration-antiphon commemoration-versicle
#
# A line beginning `register-ok` lists corpus keys to leave out of the
# translation review's mixed-register list.

# The Saturday Vespers books appoint the Saturday psalter for I Vespers of
# these Sundays.
#
# The hymn, short responsory and versicle are not proper to the three
# Septuagesimatide Sundays: the Monastic Diurnal sends them to the Psalter at
# both hours — "Short R., Hymn and V. as in the Psalter, p. 39" at Lauds and
# "p. 114" at Vespers (pp. 236, 237, 239, 240, 242, 243). The Psalter prints
# the one substitution the season does make, at Sunday Lauds (p. 40): "On
# Septuagesima, Sexagesima, and Quinquagesima Sundays, V. Lord, thou hast been
# our refuge. R. From one generation to another" — which is the versicle-lauds
# each proper file already carries from the parish books. The chapter is the
# only other proper element, and is now supplied at Vespers too.
