Daily Office

The hours of the Benedictine Office in English — Lauds through Compline, every day of the year.

Point a phone camera at the code and the Office opens. The link carries no date, so it always arrives at today's hours — a printed card on a noticeboard will not go stale.

Putting it on a noticeboard

Print a card lays this page out as a half-page notice: the cross, the code, and the address, with the site navigation left off. Print it at any size down to about an inch and a half square — below that phone cameras start to struggle.

The code is drawn as vector artwork, so it stays sharp however large it is printed. Photocopying is fine; keep the pale border around the code, as scanners use it to find the edge.
